# SPB Fuel Intelligence — состояние MVP

Дата контрольного прогона: 11 сентября 2026 года.

## Реализовано

Полный путь `live public sources → raw capture → normalizers → conservative station matcher → provenance deduplication → Evidence Engine → HTTP API → mobile/desktop web UI` работает локально.

Последний полный контрольный refresh занял около 30 секунд и обновил 11 из 11 публичных каналов. В том числе успешно получены 105 из 105 official station details «Газпромнефти» в AOI. Снимок содержит 2 001 консервативный station-candidate, 21 162 grade-level evidence records и текущий Sber/2GIS baseline 913 физических точек. Точные значения меняются при каждом обновлении.

Официальный слой «Газпромнефти» содержит 70 точек с городом `Санкт-Петербург` и 35 точек ближайшей области/поселений. На 97 из 105 АЗС есть хотя бы один explicit `rest.avail`; на 89 есть хотя бы одна доступная марка, а восемь ответов содержат только `UNKNOWN`. После объединения обычных и брендированных вариантов официальный срез даёт: АИ-92 — 26 available / 71 not available / 6 unknown; АИ-95 — 33 / 64 / 6; АИ-100 — 8 / 22 / 5; ДТ — 86 / 3 / 6; LPG — 3 / 1 / 2.

## Почему это отличается от стандартной карты

Стандартная карта обычно смешивает штатный ассортимент, цену и текущее наличие. Здесь эти понятия разделены. Отсутствие ответа не становится отрицательным фактом, зависимые копии одного upstream не считаются независимыми подтверждениями, а конфликт явно показывается пользователю.

Дополнительно MVP ведёт временную историю по каждой паре `АЗС × марка`: фиксирует переходы `не было → появилось` и `было → пропало`, длительность непрерывного состояния и уверенность перехода. Первое наблюдение не выдаётся за поставку, а формулировка «возможное пополнение» не обещает известный объём топлива.

## Поиск для телефона

Поиск разделён на два намерения, чтобы строка не превращалась в ловушку:

- обычный ввод фильтрует по известной сети или адресу АЗС;
- кнопка **«Найти рядом»** или Enter трактует текст как адрес/место, получает одну координату и показывает АЗС в радиусе 5 км, отсортированные по расстоянию;
- **«Рядом со мной»** использует только явно разрешённую геолокацию браузера и тот же радиус;
- после перемещения карты пальцем или мышью появляется кнопка **«Искать в этой области»**. Карта получила `touch-action: none`, поэтому жест перетаскивания не должен превращаться в прокрутку страницы на телефоне.

Геокодирование вызывается лишь явным действием пользователя, не работает как автодополнение, кешируется и ограничено одним запросом в секунду. Для публичной статической версии предусмотрен такой же разовый запрос из браузера; при недоступности сервиса пользователь может выбрать область непосредственно на карте. Это соответствует [политике Nominatim](https://operations.osmfoundation.org/policies/nominatim/).

После двух реальных live-снимков отслеживается 6 721 пара `АЗС × марка`. Второй снимок зафиксировал 524 изменения итогового статуса: 38 переходов от отрицательного к положительному, 17 обратных переходов, 99 новых положительных сигналов после неизвестного/конфликтного состояния и 370 прочих изменений степени уверенности или ограничений. Для АИ-95 интерфейс показал 29 недавних появлений. Эти числа — изменения наблюдаемых сигналов, а не 524 поставки топлива.

## Что ещё нужно до публичного продукта

- завершить проверенный crosswalk/alias-registry и убрать оставшиеся дубли карточек;
- добавить административные районы СПб по валидированным полигонам;
- накопить достаточно временных рядов для калиброванного прогноза «доживёт ли наличие до приезда»;
- добавить production-хранилище, scheduler, мониторинг collectors и rate limiting;
- получить легальное разрешение/ключи источников для регулярной эксплуатации;
- провести полевые проверки выбранных АЗС и калибровку confidence;
- развернуть HTTPS-хостинг после решения по режиму доступа.

Локальный refresh защищён same-origin custom header, блокировкой параллельного запуска и четырёхминутным cooldown. Leaflet 1.9.4 хранится внутри пакета; только картографические тайлы остаются сетевой зависимостью.

Итог: **MVP уже можно использовать как локальный инструмент принятия решения и демонстрацию продукта; публиковать его как гарантированный realtime-сервис пока рано.**
