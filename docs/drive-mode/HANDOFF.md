## Как закрыть клуб (только после прямого «да» пользователя)

Сейчас `https://195.133.61.136/club/health` показывает `"mode":"test"`. Этап задаёт строка `CLUB_GATE` в `/etc/spbfi/env` на сервере. Подробнее — раздел «Этапы клуба» в `docs/club.md`.

| `CLUB_GATE` | Что видят |
|---|---|
| не задан (тест) | клуб видят только вошедшие, остальные пользуются приложением как раньше |
| `invite` | всем показывается «Есть приглашение в клуб своих? Вступить» |
| `closed` | без членства нельзя отмечать, видеть имена и получать уведомления; остальные видят экран входа |

Задуманный порядок: сначала `invite`, свои вступают по приглашениям («👥 Клуб» → «Создать приглашение» → «Отправить приглашение»), потом `closed`.

Команды выполняются в Git Bash на ПК пользователя, с ключом `~/.ssh/spbfi_club_ed25519` — тем же, что использует `server/remote.sh`:

```bash
spbfi() { ssh -i ~/.ssh/spbfi_club_ed25519 -o IdentitiesOnly=yes -o StrictHostKeyChecking=accept-new -o UserKnownHostsFile="$HOME/.ssh/known_hosts" root@195.133.61.136 "$@"; }
# Текущий этап. Выводится только эта строка: остальные строки файла — хеши секретов, их не показывать.
spbfi "grep '^CLUB_GATE=' /etc/spbfi/env || echo 'не задан: тест'"
# Закрыть. Чтобы открыть приглашения, вместо closed написать invite.
spbfi "sed -i '/^CLUB_GATE=/d' /etc/spbfi/env && echo CLUB_GATE=closed >> /etc/spbfi/env && systemctl restart spbfi-club"
# Проверить: должно быть "mode":"closed" и "club":true.
curl -s https://195.133.61.136/club/health
```

Вернуть тестовый режим: `spbfi "sed -i '/^CLUB_GATE=/d' /etc/spbfi/env && systemctl restart spbfi-club"`.

Ключ владельца и другие секреты не трогать и не спрашивать.
