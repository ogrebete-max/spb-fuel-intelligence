# Памятка участнику клуба «Топливо СПб»

Короткий текст, который владелец может переслать новым участникам вместе с приглашением. Всё то же самое есть в приложении: «👥 Клуб» → «Как пользоваться клубом».

---

**Что это.** Закрытый клуб своих: где сейчас есть бензин — по отметкам людей, которые сами стоят у колонок. Вход только по приглашению.

**Как вступить**
- **Android:** откройте ссылку из приглашения, напишите имя, отметьте правила и нажмите «Вступить в клуб». Потом в меню браузера (⋮) — «Добавить на главный экран» или «Установить приложение».
- **iPhone:** откройте ссылку в Safari → «Поделиться» → «На экран „Домой“» → откройте приложение с иконки и введите код уже там.
- Сразу после вступления нажмите **«🔑 Запомнить вход»**. Если приложение сбросится или смените телефон, вернётесь по Face ID или отпечатку.

**Как пользоваться**
1. Видите АЗС — откройте её карточку и отметьте, что есть на колонках и какая очередь. Отметка живёт 45 минут и сразу видна всем своим.
2. Вы на заправке, которую отметил другой? Всё так — 👍, неправда — 👎. Вдали от заправки эти кнопки не работают: оценивает только тот, кто видит колонки сам, и только в первый час после отметки.
3. Отметка помогла — скажите 🙏 «Спасибо».
4. За пользу клуб даёт рукопожатия 🤝: +1 за отметку, +3 если её подтвердили, +2 за «спасибо». Это не бензин и не деньги — просто уважение своих.
5. Хотите позвать своего — «👥 Клуб» → «Создать приглашение», у каждого их три. Кончились — «🎟 Попросить ещё приглашений у владельца».
6. Вопросы и новости — в чате клуба: «👥 Клуб» → «💬 Чат клуба в Telegram».

**Если приложение пишет «Место приблизительное»**
Нажмите «что делать» и посмотрите на маленькую карту. Точка стоит там, где вы, — нажмите «Да, точка на месте», и всё заработает. Точка не там — приложение покажет, какой переключатель включить в телефоне.

**Если вылетели из клуба**
- Вход запоминали — на экране входа нажмите «🔑 Я уже в клубе».
- Не запоминали — введите тот же код приглашения: он пускает вас снова целую неделю.
- Есть другое устройство, где вы в клубе, — там «👥 Клуб» → «Войти на другом устройстве», и введите показанный код.
- Ничего не помогло — напишите тому, кто вас пригласил, или владельцу: он даст код для входа.

**Правила**
1. Клуб — только для своих. Приглашайте тех, за кого ручаетесь сами. Код приглашения — только для того, кого пригласили.
2. Отмечайте только то, что видите своими глазами прямо сейчас. Не пересказывайте чаты и слухи.
3. Не уверены — не отмечайте. Лучше промолчать, чем отправить своих на пустую заправку.
4. Ложную отметку опровергают 👎. Пять 👎 от разных людей — и автор выбывает из клуба, пока владелец не вернёт. Кто пригласил — отвечает за приглашённого.
5. Не показывайте приложение и отметки посторонним и не выкладывайте их в общие чаты.
