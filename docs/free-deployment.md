# Бесплатный первый запуск

Для первых 10–20 пользователей код остаётся в **приватном GitHub-репозитории**. GitHub Actions каждые 15 минут забирает только публичные station-level источники, пересобирает снимок и сохраняет историю переходов «не было → появилось». Для открытой карты понадобится бесплатный статический хостинг, который умеет читать приватный репозиторий (например, Cloudflare Pages).

## Как это устроено

```text
Публичные источники → GitHub Actions (15 мин) → снимок + history.json
                                                ↓
                                статическая карта → отдельный бесплатный хостинг
```

В репозитории сохраняется только `data/history.json`, необходимый для признаков «появилось недавно» и непрерывной длительности статуса. Сырые живые ответы и собранный снимок не коммитятся: они пересобираются при следующем запуске. Никакие ключи, аккаунты АЗС или платные API не нужны.

## Что нужно сделать один раз

1. Создать бесплатный аккаунт GitHub.
2. Хранить исходный код в приватном `ogrebete-max/spb-fuel-intelligence`.
3. На вкладке **Actions** вручную запустить `Refresh fuel data and preserve history` один раз, когда будет нужен очередной снимок.
4. Перед первым публичным запуском подключить бесплатный Cloudflare Pages к этому приватному репозиторию; домен покупать не требуется.

## Ограничения, о которых говорим честно

- Публичная страница будет обновляться по расписанию, а не по кнопке в браузере. На ней явно будет написано «Автообновление: 15 мин».
- GitHub не гарантирует запуск ровно в минуту cron, поэтому фактическая задержка может быть больше 15 минут.
- Это не доказательство физического остатка в резервуаре. «Появилось недавно» означает подтверждённое изменение доступного station-level сигнала; бензовоз, объём поставки и будущая длительность продажи не выдумываются.
- Источники могут временно отвечать ошибкой. Последний корректный снимок остаётся виден, а возраст данных показывается в интерфейсе.

## Почему не GitHub Pages и не бесплатный Render

Бесплатный GitHub Pages рассчитан на публичные репозитории, а исходники этого проекта намеренно закрыты. У бесплатного Render веб-сервис засыпает после 15 минут без запросов, а локальная файловая система стирается при перезапуске. Для этой карты это особенно плохо: история состояний — ключевая функция. Поэтому репозиторий остаётся приватным, а публичную статическую карту позже отдаст отдельный хостинг.

## Когда понадобится платный вариант

Переход имеет смысл, когда появятся push-уведомления, личные аккаунты, частые обновления, закрытые ключи или заметно больше пользователей. Тогда можно добавить недорогой сервер и базу данных, но для первых 10–20 пользователей это преждевременно. Текущий вариант стоит **0 ₽/мес.** при соблюдении бесплатных лимитов GitHub для публичного репозитория.
