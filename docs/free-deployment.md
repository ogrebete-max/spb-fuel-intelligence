# Бесплатная эксплуатация

Проект некоммерческий и целиком помещается в бесплатные лимиты GitHub.

```text
21 публичный источник → GitHub Actions (каждые 10 мин) → снимок + история
                                                        ↓
                                          статическая карта → GitHub Pages
```

## Почему репозиторий публичный

У приватного репозитория Actions расходуют бесплатную квоту 2 000 минут в месяц. Один прогон занимает 2–3 минуты; при обновлении раз в 10 минут это около 8 000 минут в месяц, то есть квота кончается примерно за неделю, после чего обновления просто встают до следующего месяца.

У публичного репозитория Actions бесплатны без ограничения по минутам, а GitHub Pages раздаётся из того же репозитория. Поэтому отдельный репозиторий сайта и SSH‑ключ развёртывания больше не нужны: workflow публикует артефакт напрямую через `actions/deploy-pages`.

## Где живёт состояние

История переходов «не было → появилось» — это состояние, а не исходный код. Она хранится в отдельной ветке `state` одним коммитом, который каждый прогон перезаписывается force‑push’ем. Иначе многомегабайтный `data/history.json` переписывался бы в историю `main` 144 раза в сутки и репозиторий рос бы на сотни мегабайт в день.

Сырые ответы источников и собранный снимок не коммитятся вообще: они пересобираются при следующем запуске.

## Что честно говорим пользователю

- GitHub не гарантирует запуск cron минута в минуту, поэтому фактический интервал плавает и может быть больше 10 минут. На странице всегда виден реальный возраст данных.
- Опубликованный снимок продолжает стареть в браузере. Каждый ответ несёт TTL своего сигнала, и страница сама гасит протухшие ответы вместо того, чтобы показывать бодрое «можно заправиться» спустя три часа.
- Это не доказательство физического остатка в резервуаре. «Появилось недавно» означает подтверждённое изменение доступного station‑level сигнала.
- Источники временно отвечают ошибкой. Последний корректный снимок остаётся виден, а результат каждого коллектора публикуется в `static-data/collectors.json`.

## Когда понадобится платный вариант

Переход имеет смысл, когда появятся push‑уведомления, личные аккаунты, закрытые ключи или заметно больше пользователей. Тогда нужны сервер и база данных. Для текущей раздачи знакомым это преждевременно: стоимость — **0 ₽/мес.**
