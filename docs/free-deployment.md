# Бесплатный первый запуск

Для первых 10–20 пользователей выбран бесплатный вариант: **GitHub Pages + GitHub Actions**. Это не сервер, который постоянно работает за деньги. Пользователь открывает обычный быстрый сайт, а GitHub Actions каждые 15 минут забирает только публичные station-level источники, пересобирает снимок и сохраняет историю переходов «не было → появилось».

## Как это устроено

```text
Публичные источники → GitHub Actions (15 мин) → снимок + history.json
                                                ↓
                                     статическая карта → GitHub Pages
```

В репозитории сохраняется только `data/history.json`, необходимый для признаков «появилось недавно» и непрерывной длительности статуса. Сырые живые ответы и собранный снимок не коммитятся: они пересобираются при следующем запуске. Никакие ключи, аккаунты АЗС или платные API не нужны.

## Что нужно сделать один раз

1. Создать бесплатный аккаунт GitHub.
2. Создать **публичный** пустой репозиторий, например `spb-fuel-intelligence`.
3. Загрузить в него содержимое этой папки проекта.
4. В настройках репозитория открыть **Settings → Pages → Source: GitHub Actions**.
5. На вкладке **Actions** вручную запустить `Refresh fuel data and deploy public map` один раз.

После первого успешного запуска GitHub покажет адрес вида `https://<логин>.github.io/spb-fuel-intelligence/`. Домен покупать не требуется. Обычная ссылка GitHub подходит для теста с первыми пользователями.

## Ограничения, о которых говорим честно

- Публичная страница обновляется по расписанию, а не по кнопке в браузере. На ней явно написано «Автообновление: 15 мин».
- GitHub не гарантирует запуск ровно в минуту cron, поэтому фактическая задержка может быть больше 15 минут.
- Это не доказательство физического остатка в резервуаре. «Появилось недавно» означает подтверждённое изменение доступного station-level сигнала; бензовоз, объём поставки и будущая длительность продажи не выдумываются.
- Источники могут временно отвечать ошибкой. Последний корректный снимок остаётся виден, а возраст данных показывается в интерфейсе.

## Почему не бесплатный Render

У бесплатного Render веб-сервис засыпает после 15 минут без запросов, а локальная файловая система стирается при перезапуске. Для этой карты это особенно плохо: история состояний — ключевая функция. GitHub Pages не требует постоянно работающего процесса, а `history.json` остаётся в репозитории.

## Когда понадобится платный вариант

Переход имеет смысл, когда появятся push-уведомления, личные аккаунты, частые обновления, закрытые ключи или заметно больше пользователей. Тогда можно добавить недорогой сервер и базу данных, но для первых 10–20 пользователей это преждевременно. Текущий вариант стоит **0 ₽/мес.** при соблюдении бесплатных лимитов GitHub для публичного репозитория.
