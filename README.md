# SPB Fuel Intelligence

Карта наличия топлива на АЗС Санкт-Петербурга и ближней Ленинградской области. Приложение показывает не общую метку «бензин есть/нет», а отдельный ответ по АИ‑92, АИ‑95, АИ‑98, АИ‑100, ДТ и газу — с возрастом сигнала, числом источников, оценкой достоверности, ценой, очередью, лимитом и объяснением, откуда это взялось.

**Публичная карта: <https://ogrebete-max.github.io/spb-fuel-intelligence/>**

Данные обновляются автоматически примерно каждые 10 минут через GitHub Actions. Репозиторий публичный, поэтому Actions и хостинг бесплатны без ограничений по минутам. Cron у GitHub служит только будильником: бесплатное расписание пропускает большинство частых слотов, поэтому один запуск сам проходит цепочку слотов на несколько часов вперёд — подробности в [`docs/free-deployment.md`](docs/free-deployment.md).

## Установка на телефон

Открыть <https://ogrebete-max.github.io/spb-fuel-intelligence/> и нажать **«Установить»** в шапке.

- **iPhone / iPad:** только в Safari → «Поделиться» → «На экран “Домой”». В Chrome на iOS установка недоступна.
- **Android:** меню браузера → «Установить приложение».

После установки приложение открывается без адресной строки, а интерфейс и последний загруженный снимок работают без сети. Возраст данных всегда виден на карточке.

## Аналитика качества

Приложение считает не только посещения, но и полезность решения: поиск → карточка АЗС → маршрут → фактическая отметка у колонки. Отметки не дальше 500 м от АЗС проверяют показанную вероятность через accuracy и Brier score — отдельно по возрасту сигнала, статусу и источнику. Закрытая панель владельца находится по адресу `/analytics.html` и требует секрет `ANALYTICS_ADMIN_KEY` из Cloudflare Worker.

Текст поиска, точные координаты, IP и рекламные идентификаторы в аналитике не сохраняются. Подробности и настройка — [`docs/analytics.md`](docs/analytics.md), исследование отличий и новых подключений — [`docs/analytics-intelligence-research.md`](docs/analytics-intelligence-research.md).

## Локальный запуск

Проще всего в Windows — открыть `START_APP.cmd`; браузер откроется на <http://127.0.0.1:8765>. Из PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

Локально кнопка **«Обновить данные»** делает живые запросы сразу. На публичной странице она заменяется честной пометкой об автообновлении.

Ручной сбор без сервера:

```bash
python scripts/refresh_live.py          # собрать все источники, пересобрать снимок и историю
python scripts/build_static_site.py --output site
```

## Источники

В снимке участвует 21 анонимный публичный канал; ключи и аккаунты не нужны.

**Прямые ответы о наличии по маркам**

| Источник | Что даёт |
|---|---|
| Газпромнефть (`gpnbonus.ru`) | официальный остаток по каждой марке, единственный `official_stock` |
| `gdezapravka.ru` | список доступных сейчас марок, очередь, возраст сообщения (AOI собирается тайлами: ответ обрезается на 500 строках) |
| `tofuel.ru` | вердикт по марке с голосами, confidence и временем сообщения |
| `t.me/s/benzinspb78` | публичное веб‑превью канала: подтверждения водителей с адресом, марками, очередью, лимитом, ценами и точными координатами |
| `gdebenz.ru`, `benzas.ru` | сообщения водителей поверх общей базы OSM |
| `benzinest.ru`, `benzonavt.ru`, `tutbenz.app`, гдебензин.рф | импортированные и распознанные статусы |
| `sberazs.ru` | статус и лимит литров по платёжной активности |
| `tboo.ru/gpn` | сводный сигнал сети и прогноз по платежам |

**Официальные каталоги и цены** — никогда не считаются текущим остатком: Лукойл, Роснефть, Татнефть (с отметкой времени по каждой марке), Teboil, Киришиавтосервис, реестр BenzinRadar.

Полный реестр с классификацией — `config/sources.yaml`; он же виден в приложении по кнопке «Источники», разделённый на каналы, которые ответили в этом снимке, и остальные. Результат каждого коллектора публикуется как `static-data/collectors.json`.

## Как считается ответ

`UNKNOWN` никогда не превращается в «нет топлива». Каталожный ассортимент и цена сами по себе не доказывают текущий остаток. Платёжный сигнал без известной товарной позиции даёт только вероятностный результат.

Для каждой пары «АЗС × марка» вычисляется одно из семи состояний: `CAN_REFUEL`, `LIKELY_AVAILABLE`, `CONFLICT`, `LIMITED`, `LIKELY_NOT`, `CONFIRMED_NO`, `NO_FRESH_DATA`. Строгое «МОЖНО ЗАПРАВИТЬСЯ» требует официального stock‑сигнала либо двух действительно независимых свежих provenance‑кластеров.

Рядом со статусом показывается **достоверность 0–100 %**. Она складывается из силы самого сильного свежего сигнала, числа независимо согласных provenance‑кластеров и того, сколько от TTL сигнала уже прошло. Это оценка качества данных, а не измерение остатка в резервуаре.

Противоположные сигналы считаются конфликтом только при сопоставимом весе: один слабый платёжный прогноз против официального остатка не превращает ответ в «данные расходятся», а показывается сноской.

Опубликованный снимок продолжает стареть в браузере читателя, поэтому каждый ответ несёт TTL своего сигнала, и страница гасит именно те ответы, которые протухли.

«Возможно, свежее пополнение» означает только зафиксированный переход от отсутствия к наличию. Это не доказательство приезда бензовоза и не измерение объёма. Подробности — `docs/temporal-intelligence.md`.

## Структура

```
config/sources.yaml     реестр источников и их классификация
scripts/refresh_live.py сбор всех каналов и пересборка снимка
scripts/collectors.py   источники, которым мало одного GET: тайлы, POST, HTML, Telegram
scripts/build_snapshot.py  нормализация, матчинг станций, дедупликация provenance
scripts/build_static_site.py  экспорт статической карты для GitHub Pages
src/normalizers.py      нормализаторы Phase 0
src/sources_live.py     нормализаторы источников, добавленных после Phase 0
src/evidence_engine.py  семь состояний, TTL, оценка достоверности
src/history.py          история «не было → появилось» по каждой паре АЗС × марка
src/station_matcher.py  канонические карточки АЗС
src/last_seen.py        АЗС, которых нет в снимке только потому, что упал их источник
src/server.py           локальный HTTP API без внешних зависимостей
web/                    интерфейс и PWA
worker/                 общие отметки, push и приватная агрегатная аналитика
```
