# SPB Fuel Intelligence — работающий локальный MVP

## Публичный бесплатный запуск

Проект подготовлен к публикации на GitHub Pages: GitHub Actions раз в 15 минут получает публичные источники, обновляет историю статусов и публикует статическую карту. Инструкция без серверов и оплаты: [`docs/free-deployment.md`](docs/free-deployment.md).

Локальный режим остаётся удобнее для разработки: кнопка обновления делает запросы сразу. На публичной странице кнопка заменяется честной пометкой об автоматическом обновлении.

Персональное evidence-first веб-приложение для Санкт-Петербурга и ближайшей Ленинградской области. Оно показывает не просто метку «бензин есть/нет», а отдельный результат для АИ‑92, АИ‑95, АИ‑98, АИ‑100, ДТ и LPG с возрастом сигнала, историей появления, ценой, очередью, лимитом и объяснением происхождения данных.

## Быстрый запуск

Самый простой способ в Windows — открыть `START_APP.cmd`. Откроется браузер по адресу <http://127.0.0.1:8765>. Окно сервера должно оставаться открытым; остановка — `Ctrl+C`.

Из PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

В приложении нажмите **«Обновить данные»**, чтобы заново получить публичные ответы, перестроить снимок и записать историю переходов. Refresh проверяет 10 AOI/bulk endpoints и официальный station-detail слой «Газпромнефти»; контрольный сквозной прогон занял около 30 секунд. Если интернет недоступен, приложение продолжит работать с последним успешным снимком.

## Что уже работает

- список и интерактивная карта АЗС;
- фильтры по СПб/ближней ЛО, марке топлива, статусу, сети и адресу;
- сортировка по итоговому статусу, свежести, цене и расстоянию;
- геолокация «Рядом со мной» с явного разрешения браузера;
- семь честных пользовательских состояний;
- карточка каждой точки с матрицей марок и разделом «Почему такой результат?»;
- дедупликация upstream/provenance: зависимые агрегаторы не превращаются в несколько подтверждений;
- текущие цены, очередь и литровые лимиты, когда источник их передаёт;
- ручное обновление 11 анонимно доступных HTTP-каналов, включая 105 official details «Газпромнефти»;
- история переходов по каждой паре `АЗС × марка`, бейджи «Появилось недавно» и длительность непрерывного статуса;
- сортировка и фильтр по недавно появившемуся топливу;
- локальный API без внешних Python-зависимостей.

## Важная семантика

`UNKNOWN` никогда не превращается в «нет топлива». Каталожный ассортимент и цена сами по себе не доказывают текущий остаток. Платёжный сигнал без известной товарной позиции даёт только вероятностный результат. Строгое «МОЖНО ЗАПРАВИТЬСЯ» или «ПОДТВЕРЖДЕНО НЕТ» требует официального stock-сигнала либо двух действительно независимых свежих provenance-кластеров.

«Возможно, свежее пополнение» означает только зафиксированный переход от отсутствия к наличию. Это не доказательство приезда бензовоза и не измерение объёма. Первое положительное наблюдение не считается пополнением. Подробная семантика описана в `docs/temporal-intelligence.md`.

Количество **карточек источников** может быть больше числа физических АЗС: matcher намеренно не склеивает точки только по близости координат. Интерфейс отдельно показывает текущий Sber/2GIS baseline физических точек. До ручной валидации alias/crosswalk это безопаснее, чем ошибочно объединить соседние станции.

```powershell
python -m unittest discover -s tests -v
python scripts/qa_package.py

```

Актуальная автоматическая проверка: 37 unit-тестов Evidence Engine, temporal history, normalizers, repository и station matcher; отдельный package QA проверяет 24 источника и отсутствие секретов в fixtures.

## Структура

- `web/` — адаптивный интерфейс и локально закреплённый Leaflet 1.9.4;
- `src/server.py` — локальный HTTP API и безопасный refresh endpoint;
- `src/evidence_engine.py` — расчёт семи итоговых состояний;
- `src/station_matcher.py` — консервативное объединение station IDs;
- `src/normalizers.py` — нормализация источников;
- `scripts/refresh-live.ps1` — bbox/AOI-сбор публичных данных;
- `data/stations.json` — последний собранный рабочий снимок;
- `data/history.json` — накопленная история station-grade статусов и переходов;
- `data/live/` — живые raw-ответы для воспроизводимости;
- `docs/phase0-results.md` — подтверждённые возможности и coverage;
- `docs/source-capability-matrix.md` — матрица всех 24 источников;
- `docs/provenance-map.md` — карта upstream-зависимостей;
- `config/sources.yaml` — source registry;
- `tests/fixtures/` — sanitized evidence fixtures.

## Текущие ограничения

Это локальный личный MVP, не публичный production-сервис. Он не гарантирует физический остаток к моменту приезда, не обходит авторизацию/CAPTCHA и не использует закрытые API. Benzuber требует ключ, Alfa Fuel требует ручной HAR мобильного приложения, часть официальных сетей отдаёт только ассортимент. Автоматическая фоновая работа прекращается при выключении ноутбука.
